# Student Information System

A beautiful, glassmorphism-styled web application to display basic student details.

## Features
- Displays Student Name, Register Number, and Programme.
- Interactive "Show Details" button with smooth animations.
- Responsive and modern UI.

## Technologies Used
- HTML5
- CSS3 (Vanilla)
- JavaScript (Vanilla)

## How to run
Simply open `index.html` in your web browser.
